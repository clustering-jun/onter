# 변경 기록

모두 2026-11-18. 현재 상태는 `01_설계.md`.

## 1차: 첫 구현

탭 10개, 지도(Leaflet + OpenStreetMap), 단지 카드, 추천·실행 계획·사전·사례·해피콜·분석·지식 그래프·안내. 상태 7종 구분, 후보 부족 때의 채우는 순서, 확인된 필요, LLM 3종(근거 문장·점검표·묶음 설명), 지식 그래프 시제품을 `/kg/`에 붙임.

## 2차: 지도와 단지 카드

- 지도의 점을 키우고 타일 투명도 90%, 좌우 상자를 넓힘. 지사를 고르면 그 지사로 이동.
- 마우스를 올렸을 때의 도움말을 키움. 단지 유형마다 설명 추가('원격형' = 주변 시설이 먼 단지).
- 단지 카드에 주소, 타일 6개, 전체 단지 중 위치, 필요가 큰 분야. 월별 차트를 세로축·연도 구분이 있는 막대로 교체.
- 해피콜을 전체 관리소 평균·순위와 견줘 표시, 응답이 적으면 경고.
- 단지 현황에 통합표의 나머지 자료 추가: 기본 정보, 10세 단위 연령, 지표 원값, 고독사 기록, 연도별 집계, 최근 기록, 홈닥터 월별, 협력·회의·일자리.
- 추천: '제외 ▾' 메뉴가 카드에 가려 안 보이던 문제 수정.
- 사례 카드: 목록 + 상세 구조, 짧은 제목, 필터.
- 실행 계획 달력을 6열 × 2행으로.

## 3차: 글꼴과 색

- Pretendard로 교체, 모든 글자 한 단계 확대.
- 지도 숫자 기준을 빨강 계열로. 0이 대부분인 자료(고독사 기록, 우선 검토 분야 수)는 0 / 1 / 2~3 / 4 이상으로 나눔.
- 단지 현황의 고독사 기록: 0건이면 한 줄, 있으면 연도 칸.

## 4차: 머리, 사진, 창 크기 대응

- 머리의 로고 상자와 부제 삭제.
- 글자 크기를 rem으로 바꾸고 창 너비에 따라 변하게 함.
- 타일을 이름 → 값 → 보조 설명 순서의 가운데 정렬로.
- 단지 현황에 정사각형 단지 사진(`web/img/complex/`).
- 걸림돌·해결: 격자표를 유형별 요약 표와 4열 표로 교체.
- 해피콜의 '만족도와 프로그램 공급의 관계' 삭제.

## 5~8차: 여백, 색 통일, 사전 재설계, 목차

- 여백과 줄 간격 확대, 본문 최대 폭 1500px.
- 지도 색을 ColorBrewer OrRd·GnBu로 통일, 단지 유형은 청록·테라코타·짙은 남청.
- 프로그램 사전을 카드 목록 → 상세 화면 두 단계로.
- 머리(탭) 고정, 긴 화면에 목차.
- '지식 지도'를 'Knowledge Graph'로 바꾸고 글꼴·색·글자 크기를 플랫폼에 맞춤.
- **서버가 요청이 몰리면 죽는 문제 수정**: 계산을 일꾼 스레드 하나로 모음.

## 9~14차: 다듬기

- 지도의 주거복지사·활동 기록 필터 삭제.
- 목차를 눌렀을 때 선택 표시가 안 맞던 문제 수정(나란한 상자, 고정 표시).
- Knowledge Graph 검색 창 확대, 사례 제목 줄이기.
- 해피콜 주민 의견을 분류 순위 + 대표 의견 두 칸으로.
- 안내의 '불확실한 것의 표시', '자료와 문서', 분석의 '실험 결과 표' 삭제.
- **프로그램 추천을 한 화면 세 칸으로 재설계**(조절 / 목록 / 상세). 목록은 순위·분야별 전환.
- **LLM은 화면에 들어가면 자동 생성**. 요청·다시 요청 버튼 삭제.
- 추천의 걸림돌·해결을 표로. 모든 탭의 배율을 지도 탭과 같은 90%로.

## 15차: 코드 정리

- CSS: 안 쓰는 클래스의 규칙과, 같은 선택자에서 뒤에 다시 정해 죽어 있던 선언을 삭제(36.7KB → 31.5KB). 규칙 순서는 그대로. 10개 화면에서 결과가 같음을 확인.
- 목차의 스크롤 리스너가 화면을 그릴 때마다 쌓이던 것을 한 번만 걸게 함.
- 문서를 현재 상태(`01_설계.md`)와 변경 기록(이 문서)으로 나눔.

## 16차: LLM 미리 만들기와 공개 시연판

- `tools/prefill_llm.py`: 묶음 설명·근거 문장·점검표를 미리 만들어 캐시에 채움. 캐시는 한 줄에 한 건, 2초마다 모아 쓰고 임시 파일을 바꿔치기해 저장.
- 점검표·묶음 설명: 서버 오류는 캐시에 남기지 않음. 묶음 설명은 LLM이 꺼져 있어도 캐시에 있으면 씀.
- `tools/build_static.py`와 `web/js/static.js`: 서버 없이 도는 정적 판. 화면의 주소를 상대 경로로 바꿈.

## 17차: 사진과 지도 반짝임

- 단지 사진 318곳(`web/img/complex/`, 긴 변 1200px 사본).

## 18차: 색·포인트 모양 확정, 복지서비스

- 지도 색을 시안에서 골라 확정: 유형은 파랑·빨강·남청, 숫자 기준은 살구→진빨강 / 회청→남색, 0건은 흰 원.
- 포인트 모양 확정: 반투명 원 + 같은 색 진한 테두리(`PointCanvas`). 고른 단지는 진하게 칠하고 이름·주소 표지를 띄움.
- 정부·지자체 복지서비스(한국사회보장정보원 목록 5,289건): `tools/welfare_services/fetch.py`로 받아 `data/processed/welfare_services_v1/`에 저장. 프로그램 사전 탭 안의 화면(`#/programs/welfare`)과 단지 현황의 지역 요약. 인증키는 `project/.secrets/`(저장소 제외).

## 19차: 강조색, 지도 상자, 시연판 격자 확대

- 강조색을 진초록으로, 선택 표시는 옅은 초록 면 + 진초록 글자.
- 지도: 단지를 누르면 원 위에 설명 상자(단지명·주소·공급 유형·세대 수), 지도 빈 곳을 누르면 닫힘. 상자와 범례는 반투명.
- 시연판 격자 확대: 추천 6 × 4, 실행 계획 예산 6 × 프로그램 수 6 × 인력 3. 같은 묶음은 한 번만 실음.
- 안내에 만든 사람들, 사진 캡션, 탭 이름(복지 프로그램 사전).

## 21차: 단지 현황의 작은 지도

- 단지 현황 오른쪽 위에 작은 지도(`tabs/minimap.js`): 지금 보는 단지는 검은 테두리 원과 이름표, 나머지 단지는 유형 색의 반투명 원. 다른 원을 누르면 그 단지로 바뀌고, 위의 검색 상자에 이름(지사도 가능)을 쳐서 바꿀 수도 있다. 쪽을 내릴 때 걸리지 않게 휠 확대는 끔.
- 고침: 주소창이 `#/complex/단지ID`일 때 단지를 바꾸면 옛 ID가 다시 적용되어 되돌아가던 문제. 단지를 바꾸면 주소를 `#/complex`로 정리함.
