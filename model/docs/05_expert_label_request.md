# 전문가 검토 요청과 응답 반영

파일: `expert_request/온터_전문가_검토요청.xlsx` (만드는 코드 `make_expert_xlsx.py`). 어느 알고리즘이 낸 후보인지는 `expert_request/pool_key.csv`에만 있다. 이 파일은 전문가에게 보내지 않는다.

## 왜 필요한가

- 필요 적합 점수는 도입 기록으로 검증할 수 없다(무작위와 같음). 해피콜은 전국 분포만 준다.
- 필요 지수의 외부 검증이 한 분야(N1)뿐이다.
- 비용·인력은 추정이다.

## 시트 구성

| 시트 | 내용 | 분량 | 쓰임 |
|---|---|---|---|
| A_단지프로그램평가 | 단지 24곳 × 후보 약 14개. 필요(0~3), 실행 가능(0~3), 우선 추천(Y/N) | 338행, 60~80분 | 순위의 외부 평가(등급 NDCG), 필요와 실행의 분리 확인 |
| B_프로그램실행요건 | 96종의 초안(비용 등급·인력·장소·협력기관)과 실제 값 | 96행, 40분 | 모듈 4의 추정값 교체 |
| C_필요지표 | 지표 24개가 그 분야에 적절한지(0~3) | 24행, 10분 | 필요 지수 가중치 점검 |
| D_단지필요분야 | 같은 24곳에 여섯 분야 100점 배분 | 24행, 15분 | 필요 지수·목표 분포의 직접 검증 |

## 표본 설계

- 단지: 기록 20건 이상인 단지를 구조 유형(3) × 주거복지사 배치(2)로 층화해 24곳.
- 후보: 채택률·근거 융합·필요 적합·온터 기본값 네 방법의 상위 5개를 합치고 무작위 2개를 더해 섞었다(TREC식 풀링). 한 방법에 유리한 정답이 되지 않게 하고, 무작위 후보로 평가자의 기준선을 본다.
- 순서는 무작위이고 출처는 가렸다.

## 부탁드릴 것

- A와 D는 두 분 이상이 따로 작성(평가자 간 일치도: 가중 카파, Krippendorff α).
- 가능하면 주거복지사와 관리소장처럼 역할이 다른 분.

## 받은 뒤 할 분석

1. 평가자 간 일치도. 낮으면(α<0.4) 정답으로 쓰지 않고 불일치 자체를 보고한다.
2. 시트 A로 네 방법의 등급 NDCG@5 비교(짝지은 부트스트랩). 필요 점수와 실행 점수를 따로.
3. 시트 D와 필요 지수의 순위상관, 시트 C로 가중치 재설정 후 민감도.
4. 시트 B로 `requirements()`의 비용·인력·협력 열을 바꾸고 묶음 선택을 다시 계산.

## 전문가 편향을 줄이는 방법

- 전문가 판정으로 순위 모델을 학습시키지 않는다. 조절값 두 개(w, λ)의 선택과 평가에만 쓴다.
- 24곳 가운데 절반으로 조절값을 고르고 나머지 절반으로 확인한다.
- 전문가 판정과 도입 예측·해피콜 수요가 어긋나는 곳을 따로 표로 남긴다.

## 응답 반영 결과(2026-11-18)

받은 파일: `expert_request/온터_전문가_검토요청(완료).xlsx`. 네 시트가 모두 채워져 있다. 분석 코드 `experiments/exp_expert.py`, 표 `results/tables/e8_*.csv`, 해설 `02_experiments.md` 8절.

### 응답의 성격

- **평가자 1명.** 위 계획의 1번(평가자 간 일치도)은 할 수 없다. 그래서 '정답'이 아니라 '한 전문가의 판단'으로 다뤘다.
- 등급은 대부분 프로그램에 따라 정해졌다(필요 등급 분산의 79%, 실행 등급의 82%가 프로그램 평균으로 설명됨).
- 우선 추천 Y가 단지마다 5~6개로 거의 같다.
- 시트 D의 한 줄 의견에 시스템 산출물의 표현(유형 S3, 공급 백분위, 'N4 필요 1위', 홈닥터 실적 증감)이 들어 있다. 단지 프로파일을 보고 작성했다면 필요 지수와의 일치는 독립 검증이 아니다. **작성 과정을 확인해야 한다.**

### 계획 대비 한 것

| 계획 | 결과 | 설계에 반영 |
|---|---|---|
| 1. 평가자 간 일치도 | 할 수 없음(1명) | 두 번째 평가자 요청 |
| 2. 네 방법의 등급 NDCG@5 | 우선 추천 기준으로 네 방법 사이에 유의한 차이 없음. 모두 무작위 후보(17%)보다 높음(47~55%). 필요 적합만 쓴 방법은 필요 등급이 가장 높고 실행 등급이 뚜렷이 낮음 | 온터 기본 구조(근거 + 필요)를 유지 |
| 조절값(w, λ) 점검 | 전문가 우선 추천은 w 0.3~0.5, λ=0에서 가장 높음. 반반 검증의 이득 +0.04(95% 구간 −0.08~+0.11) | 기본값 유지(w=0.2, λ=0.25). w를 화면에서 조절 가능하게 |
| 3. 시트 D·C와 필요 지수 | 분야별 순위상관 0.52~0.96. 독립 검증은 아님. 전문가 가중치로 바꾸면 '문화와 활동'만 크게 바뀌고, 바꾼 쪽이 같은 전문가의 시트 D와 반대 방향 | 가중치 유지. '문화와 활동'을 불확실한 분야로 표시 |
| 4. 시트 B로 요건 교체 | 비용은 순위 일치(ρ=0.71), 초안이 1.5배 높음. 인력은 약한 일치(ρ≈0.35). 전문가 요건의 실행 가능성은 새 도입 AUC 0.59(규칙 기반 0.48) | **요건을 전문가 값으로 교체.** 미배치 경고 추가. 묶음 선택 기본 제약 변경. 순위에는 넣지 않음 |

### 전문가 편향을 줄이려고 지킨 것

- 순위 모델을 전문가 등급으로 학습시키지 않았다.
- 조절값은 반반 검증에서 이득이 확인되지 않아 바꾸지 않았다.
- 전문가 값으로 바꾼 것은 사실에 가까운 항목(비용, 인력, 공간, 기관)뿐이다. 초안은 지우지 않고 남겼다.

### 다시 요청할 것

1. 평가자 한 명 더(가능하면 주거복지사와 관리소장처럼 역할이 다른 분). 시트 A와 D만.
2. 단지 요약 외의 시스템 산출물을 보지 않고 작성.
3. 우선 추천 Y의 개수를 정하지 않고 판단.
