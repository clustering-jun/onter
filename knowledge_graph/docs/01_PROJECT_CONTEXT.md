# 프로젝트 맥락과 이번 구현 범위

기록일: 2026-11-18. 이 문서는 정식 웹 플랫폼에 기능을 옮길 때의 맥락 기록이다.

## 목적

온터는 **단지 단위 복지 프로그램의 선정·배분을 지원하는 시스템**이다. 고독사 예측·위기가구 발굴 시스템으로 프레이밍하지 않는다. 근거·선정 기준·주민 도달·실행 후 학습의 연결을 다룬다. 이번 지식 그래프의 역할은 관계와 근거를 시각적으로 검토하는 것이며 추천 성능 향상을 입증한 알고리즘은 아니다.

## 실제로 확인한 구조

- `data/raw`: 원자료. 이번 작업에서 변경하지 않음.
- `data/processed`: 단지 통합, 커뮤니티 NLP, 사례집, 뉴스, 해피콜, 확정 키 연결표, 월별 패널.
- `data/eda_20261117_v1`: 기존 EDA와 시각화. 정식 플랫폼과 동일하다고 취급하지 않음.
- `design`: v1~v6 연구방법론 문서.
- `model/onter`: M1 프로파일, M2 유사 단지·사례, M3 후보 순위, M4 실행 조건·묶음, 설명 검사.
- `model/outputs`: 전체 기간의 화면용 프로파일·유사도·후보·실행 조건·3,180개 상세 근거.
- `model/results`: 시간 분할 비교 실험과 LLM 설명 점검 결과.
- `tools`: 전처리·키 연결·NLP·EDA 생성 코드.
- `knowledge_graph`: 이번 작업에서 추가한 시제품·읽기 전용 스냅샷·문서. 위 기존 파이프라인의 코드를 수정하지 않음.

## 기억과 코드에서 확인한 중요한 전제

1. 단지 연결은 확정된 `complex_id`, 프로그램 연결은 기존 `std_id`를 사용한다. 이름 유사성으로 새로운 단지를 확정하지 않는다. 제주일도이동의 기존 예외 ID도 유지한다.
2. 커뮤니티 NLP의 프로그램 분류는 규칙·LLM 구조화 결과이며 전문가 독립 정답이 아니다. 유형의 통상 대상과 기록에 명시된 대상을 구분한다.
3. 사례집은 18사례의 우수 사례 중심이며 일부 각색이 있다. 사례의 기술값을 다른 단지에 일반화하지 않는다.
4. 뉴스는 원문 재사용 허락 미확인 자료가 많다. 여기서는 제목·매체·날짜·원문 링크만 표시한다.
5. 해피콜 전국·집단 수요를 단지별 관측 수요로 복제하지 않는다. 공유 관리소 점수도 개별 단지 값으로 복제하지 않는다.
6. 개인화 모델이 전국 채택률을 뚜렷이 넘지 못한 기존 실험을 숨기지 않는다. 그래프 연결의 풍부함이 추천 타당도를 보장하지 않는다.
7. M1 필요 지표는 대리변수 기반 추정이다. 표본조사로 측정된 단지별 미충족 수요가 아니다.
8. 비용은 가정에 따른 추정이고 실행 점검은 정답·성공 확률이 아니다.

## Claude의 로컬 LLM 작업과 분리

사용자는 Claude가 Ollama의 `exaone3.5:7.8b`로 설명 배치를 수행 중이라고 안내했다. 따라서 모델 서버를 새로 띄우거나 병렬 수·온도·모델 코드를 바꾸지 않았다. `model/outputs/llm/explanations_llm.jsonl`의 완성된 행과 기존 요약을 읽기만 한다. 불완전한 마지막 JSONL 행은 건너뛴다. 로컬 설명은 추천 상세에서만 선택적으로 보여 주고, 생성 문장으로 그래프 사실을 추가하지 않는다.

현재 결과 파일에서 전체 3,180행을 확인했다. 원본 자동 검사 통과와 의미·효과의 전문가 검증은 다르다. 이 시제품이 검사 기준을 변경하거나 별도 LLM 검증을 추가한 것은 아니다.

## 이번 시제품에서 하지 않은 것

정식 로그인·권한·배포, 실행 기록 입력·환류, 추천 모델 재학습, 전문가 완료 엑셀의 신규 해석, 뉴스 본문 공개, 원자료 교정, 미확정 단지 연결, 시간 분할 성능 실험은 하지 않았다. 원본 보고서·설계 문서 전체를 무차별적으로 사실 노드로 변환하지도 않았다. 의미가 정의된 구조화 자료와 모델의 실제 산출물을 우선 연결했다.
