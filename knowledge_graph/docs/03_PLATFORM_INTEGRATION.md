# 정식 웹 플랫폼 통합 메모

## 현재 시제품의 경계

Python 표준 라이브러리 HTTP 서버 + 읽기 전용 SQLite + 로컬 Cytoscape.js 3.33.1이다. Ollama·Python LLM SDK·모델 계산 코드를 import하지 않는다. 정식 인증·권한 체계가 없는 로컬 도구이며 `127.0.0.1`에만 바인딩한다. 그대로 공개 서버에 올리지 않는다.

## API

| GET 경로 | 주요 인자 | 응답 |
|---|---|---|
| `/api/stats` | - | 실제 개수·관계·소스·스냅샷 시각 |
| `/api/search` | q, kind, limit | 이름·ID·별칭 검색 |
| `/api/graph` | id, mode, limit, statuses, year | 부분 그래프 nodes/edges, 중심, 전체 이웃 수, 생략 여부 |
| `/api/node` | id | 속성·출처·관계 수·월별 추이, 후보의 선택적 LLM 설명 |
| `/api/evidence` | id, kind, offset, limit, statuses, year | 해당 점의 사례·뉴스·운영 기록을 페이지로 제공 |
| `/api/path` | from, to, statuses | 제한된 의미 관계의 최단 경로 또는 없음 |
| `/api/llm-status` | - | 완료·검사 통과 설명·템플릿 대체 개수. 새 생성 없음 |

statuses는 `observed,defined,derived,estimated,similarity,tentative`의 쉼표 목록. 빈 문자열이면 관계를 표시하지 않는다. limit는 서버에서 5~120으로 제한한다. 전체 그래프를 매번 브라우저로 보내지 않는다. 현재 화면의 내보내기는 부분 그래프이며 전체 DB 백업으로 취급하지 않는다.

## 화면에서 꼭 유지할 구분

1. 프로그램에서 여는 사례집·뉴스는 **같은 유형의 참고 근거**다. 추천 후보에서 여는 근거는 **그 후보가 실제 사용한 근거**다.
2. 기록에서 다른 사례를 볼 때도 동일 사건의 증거라고 하지 않는다. 유형 참고라고 표기한다.
3. 사례집의 장애물·해결은 원문 근거와 함께 보여 주고 다른 단지의 성공 보장으로 번역하지 않는다.
4. 뉴스는 제목·링크를 기본으로 한다. 공개 범위 검토 없이 body_masked를 정식 플랫폼에 넣지 않는다.
5. 후보·필요·유사도·분류를 색만으로 구분하지 말고 텍스트·선 스타일·출처를 함께 둔다.
6. 빈칸·없는 연결·필터로 숨긴 연결·표본 상한으로 생략된 연결을 구분한다.

## 통합 권장 순서

- 1단계: 사내/로컬 환경에서 독립 탐색기 또는 인증된 iframe으로 붙여 사용자 탐색을 검토한다. 후보 상세의 `complex_id/std_id`를 지식 그래프의 ID로 넘긴다.
- 2단계: `app.js`의 API 호출을 `GraphClient(baseUrl)`로 분리하고 `/api/knowledge/*` 같은 네임스페이스를 적용한다. 전역 CSS와 상태는 컴포넌트에 격리한다.
- 3단계: 기존 모델 산출물 완료 후 별도 작업으로 build_graph를 실행한다. DB/manifest를 하나의 버전으로 배포하고 버전이 다른 키를 혼합하지 않는다.
- 4단계: 실제 사용자에게 후보 검토에 도움이 되는지 평가한다. 경로·노드 수 증가를 추천 품질 향상으로 해석하지 않는다.

## 새 실행 기록과 전문가 판정이 들어올 때

기존 observed 기록과 분리된 출처·시점·판정자·상태를 가진 노드/관계로 추가한다. 전문가 완료 엑셀은 현재 그래프에서 새로 해석하지 않았으며, 문항·대상 키·판정 척도 대조 후 명시적 어댑터를 만들어야 한다. 주민별 민감정보는 단지 공개 그래프에 넣지 않는다. 실비·인력·비참여 사유 같은 실행 피드백도 추정값과 별도 필드로 보존한다.

## 운영

- 소스는 CSV/JSONL을 읽기만 하고 파일 해시를 남긴다. 뉴스 URL 외 외부 요청이 런타임에 필요하지 않다.
- LLM 파일은 8초 캐시로 읽으며 완성되지 않은 JSON 행은 건너뛴다. 생성·병렬 설정·재시도 정책은 Claude가 관리하는 기존 코드의 책임이다.
- Windows에서 DB 교체 중 파일 잠금을 피하려면 서버 종료 → build_graph → start 순서로 갱신한다. 각 요청의 DB 연결은 반드시 닫는다.
- 정식 운영에서는 인증·접근 권한·감사·검색 범위·민감정보 검사·API 제한을 플랫폼의 정책에 맞게 추가한다.

## 관계형 DB를 택한 이유와 확장

현재 약 2.7만 노드·12.5만 관계는 이 로컬 SQLite 인덱스로 충분히 탐색 가능하다. 그래프 DB를 새로 설치할 필요가 없으며 입력 데이터의 출처를 검증하기 쉽다. 추후 Neo4j/RDF로 옮길 경우 id/kind/rel/status/provenance 구조를 유지하고, 모델 추정과 원자료 관측을 동일 사실 트리플로 합치지 않는다. 모든 자유 텍스트를 LLM으로 다시 추출해 무차별 연결하는 방식은 이번 구현에 사용하지 않았다.
