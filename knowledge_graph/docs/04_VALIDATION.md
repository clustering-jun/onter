# 검증과 남은 과제

검증일: 2026-11-18. 그래프 규모와 해시 목록은 `data/manifest.json`, 브라우저 결과는 `data/browser_test.json`이 현재 스냅샷의 기준이다.

## 데이터·관계 검사

`python test_graph.py`의 10개 검사를 통과했다.

1. SQLite 무결성 및 연결 양 끝 노드 존재
2. 사용한 모든 원본 CSV/JSONL의 SHA256이 생성 전후 동일
3. 전국 해피콜 수요·VOC를 특정 단지에 직접 붙인 관계 없음
4. 뉴스 본문·운영 기록 raw 개인 식별 원문이 노드 속성에 없음
5. 단지×프로그램 집계가 대표 레코드만 사용
6. 청주산남2-1 → 사례 CB01 → 숙골빨래터 카드의 실제 2단계 경로
7. 운영 연도 필터와 낮은 확신도 기본 제외
8. I02 유형에서 실제 CB01_P1 레시피 열람 가능
9. 단지 ID가 빈 사례집 연결 3건을 추정해 붙이지 않음
10. HTTP 검색·관계 필터·상위 폴더 경로 접근 차단

이것은 데이터 투영과 UI 동작 검사이며 분류 내용 전체의 전문가 정답 검증이 아니다. 코드에 이미 존재하는 관계의 의미를 유지하는지 확인한 것이다.

## 브라우저 검사

Edge headless 1600×1000 및 모바일 390×844에서 다음을 통과했다.

- 실제 그래프 점의 화면 좌표를 클릭해 레시피 상세가 열림
- 선 클릭 시 연결 출처 표시 및 PNG·JSON 내보내기 확인
- 이불·세탁 프로그램 → 숙골빨래터 → 실행 방법·어려움과 해결 확인
- 출발·도착 버튼으로 구체적 근거 경로 탐색
- 원예 프로그램에서 뉴스 카드와 원문 링크 확인
- 운영 기록 연도를 2024년으로 제한
- 모든 관계 체크를 해제하면 선이 모두 사라짐
- 자료 범위·연결 규칙 대화상자 열기
- 모바일 가로 넘침 없음
- JavaScript 실행 오류 없음

화면 기록은 `docs/screenshots/01~06*.png`에 있다. 기본 배치는 원형·방사형 고정 좌표를 제거하고 CoSE force-directed 레이아웃으로 바꿨다. 연결과 노드 크기를 바탕으로 자연스럽게 모이며, 배치 위치 자체는 분석 결과나 거리 측정치가 아니다. 다시 배치할 때 위치는 달라질 수 있다. 주변 확장 시 기존 좌표를 시작점으로 사용해 맥락 변화를 줄인다.

## 로컬 실행 확인

`start.ps1 -NoBrowser`, `stop.ps1`로 이 폴더의 서버만 시작·종료되는 것을 확인했다. localhost:8767의 서비스 표식을 확인하며 다른 서비스이면 종료하거나 덮어쓰지 않는다. 기존 Ollama 서버·배치 프로세스를 종료하거나 설정을 수정하지 않았다.

## 남은 과제

- 전문가가 유형 연결·사례집 연결·뉴스 대응을 독립 검토해야 한다. 링크가 많다는 이유로 타당성이 확보되지 않는다.
- 경로 탐색은 5단계·방문 상한이 있어 결과 없음이 모든 길의 부재를 증명하지 않는다. 범용 허브를 배제해 의미 없는 지름길을 줄였다.
- 기관명은 기존 기사 연결표의 정확 문자열을 사용한다. 동명 기관·지자체 부서의 공식 엔터티 통합은 하지 않았다.
- 첫 화면과 근방은 표본이다. 사용자가 전체 자료와 현재 표시 수를 혼동하는지 실제 사용성 평가가 필요하다.
- 실제 사용자 조사·추천 품질 개선·실행 성과 향상은 이 시제품에서 검증하지 않았다.
- LLM 자동 검사 통과를 의미적 진실·전문가 판정으로 표현하면 안 된다. 후보 상세의 기존 설명을 읽기만 한다.
- 현재는 로컬 내부 확인용이다. 공개 배포 전 데이터 공개 범위·기사·사례집 재사용·접근 권한을 검토한다.

## 다시 검사하기

서버를 띄운 상태에서 `python test_graph.py`를 실행한다. 브라우저 자동 검사는 선택 사항으로 Playwright와 Edge가 필요하다. 이 환경에서는 번들 Playwright 경로를 사용했으며 다른 환경에서는 `PLAYWRIGHT_PATH`를 해당 설치 경로로 지정한다. `node test_browser.cjs`는 화면 기록을 새로 만든다.
