# 온터 · 프로그램 지식 지도

단지·프로그램·실제 운영 기록·사례집·뉴스·실행 조건·추천 근거를 클릭하며 살펴보는 **로컬 시각화 시제품**입니다. 정식 웹 플랫폼과 분리되어 있으며 기존 `model`, Ollama 설정, LLM 배치와 원본 데이터는 수정하지 않습니다.

## 바로 확인하기

- 실행 중 주소: **http://127.0.0.1:8767**
- 바로 사례 보기: **http://127.0.0.1:8767/#focus=program%3AI02**
- 다시 실행할 때 `start.cmd`를 더블클릭합니다. 표준 Python만 필요하며 그래프 라이브러리는 로컬에 포함했습니다.
- `stop.ps1`은 이 폴더가 띄운 서버만 종료합니다.

왼쪽 ‘이불·세탁 서비스’를 누르면, 오른쪽에 ‘숙골빨래터’ 실행 레시피가 나옵니다. **실행 방법·걸림돌 읽기**에서 대상·협력·운영·장애물과 해결을 살펴보세요. ‘원예·텃밭’에서는 뉴스 필터를 누르면 기사 제목과 원문 링크가 나옵니다. 그래프의 **선**을 누르면 해당 관계의 의미·출처 파일·행을 확인할 수 있습니다.

## 할 수 있는 것

- 프로그램·단지·사례·뉴스·기관·자원 검색, 기존 별칭 사전 검색
- 점 클릭 → 상세 내용, 사례·뉴스, 전체 관계 수
- 주변 확장, 관계 성격별 필터, 운영 기록 연도 필터
- 단지에서 추천 후보·사용된 실제 근거까지 추적
- 두 대상을 지정해 구체적 연결 경로 찾기
- 화면의 부분 그래프를 PNG·JSON으로 저장
- 390px 모바일 레이아웃

전체 그래프는 27,172개 대상·125,389개 관계입니다. 첫 화면은 분야별 대표 프로그램을 표시하며 전체 프로그램은 검색하거나 관계 수를 120개로 바꾸면 볼 수 있습니다. 대규모 관계는 유형별 제한을 두어 표본을 보여 주고, 오른쪽 근거 목록은 페이지를 넘겨 계속 확인할 수 있습니다. **화면에서 생략된 관계가 원본에 없다는 뜻은 아닙니다.**

## 그래프 해석

‘원자료의 기록’, ‘사전·정의’, ‘분류·집계’, ‘모델 추정·후보’, ‘유사도’, ‘낮은 확신도’를 구분합니다. 유사도는 같은 단지라는 뜻이 아니고, 후보는 실행 기록이 아니며, 사례집 성과 기술은 효과 검증이 아닙니다. 해피콜 전국 수요를 단지별 정답으로 붙이지 않습니다. 뉴스는 제목·링크만 보여 주며 본문은 재게시하지 않습니다. 고독사 기록과 주민 식별 원문은 포함하지 않았습니다.

로컬 LLM의 완료된 JSONL 행은 읽기만 합니다. 새 생성·재시도·Ollama 설정 변경은 하지 않습니다. 검사 통과 설명과 템플릿 대체를 구분하고, LLM 문장으로 새로운 노드나 관계를 만들지 않습니다.

## 데이터 갱신

서버를 종료한 뒤 이 폴더에서 실행합니다.

```powershell
python build_graph.py
.\start.ps1
```

`data/knowledge.sqlite`는 원본을 읽어 만든 별도 스냅샷이며 `data/manifest.json`에 입력 파일·행 수·해시가 있습니다. 원본의 수정은 자동 반영되지 않습니다. 소스 경로는 프로젝트 루트 기준 상대 경로입니다.
